# Sujato Dutta - Portfolio

This is a personal portfolio website built as part of an assignment focusing on creating a multi-page interactive web application using React Router and Tailwind CSS.

## 🚀 Features
- **Multi-page Architecture**: Separate sections for Home, Experience, Education, Skills, and Projects using `react-router-dom` with `HashRouter` for GitHub Pages compatibility.
- **Modern UI**: Polished glassmorphism design, floating animations, and fully responsive layout built with Tailwind CSS.
- **Projects Showcase**: Interactive modal views and integrated links for live demos and source code.
- **Production Ready**: Bundled with Vite and configured explicitly for streamlined deployment on `gh-pages`.

## 🛠 Tech Stack
- Frontend: React 19, TypeScript, Vite
- Styling: Tailwind CSS v4, PostCSS, Framer Motion
- Icons: Lucide React, React Icons

## 📦 Running Locally
```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deployment
This portfolio is configured to automatically build and deploy to GitHub Pages:
```bash
npm run deploy
```
